# 发布验证记录

日期：2026-11-13

交付范围：可部署的教师工作系统，使用模拟或去标识数据。本记录描述代码、依赖、部署文件和本地验证结果；公网环境尚未部署。

## 主要变更

- 工作台改为统一的深蓝／青绿色视觉，整理首页、登录、操作提示和错误文案，移除界面中的底层框架及供应商名称。
- 登录直接调用认证服务，不再从外部 CDN 加载可变版本的登录脚本。浏览器历史按账号、标签页会话隔离，损坏或不可用的缓存不会阻止页面启动；退出失败会明确提示。
- 增加授权班级列表和选择器；创建会话时校验班级权限；停用教师、机构和跨机构班级不能继续通过班级工具访问。
- 提供管理员账号／班级初始化命令，生产环境不再自动写入示例教师和幼儿。
- 生产配置强制认证、HTTPS 来源、有效配置、Redis 限流和 Celery；限制请求体及分块上传大小，拒绝跨站写请求，设置页面安全策略和禁止缓存响应。
- 健康检查有明确超时；启动恢复失败时释放运行资源；Redis 连接上限显式配置。
- 修复短 PDF 正文被解析库当作页眉丢弃的问题，增加真实 PDF 回归用例。
- 升级直接依赖及存在修复版本的传递依赖，加入开发与 Linux CPU 依赖锁文件。部署镜像使用官方、带 SHA256 校验的 CPU PyTorch 包。
- Docker 构建时生成 2,087 个知识块的词法索引，共享持久化向量索引和导出文件；生产环境拒绝空知识索引。排除本地备份、密钥和导出文件进入镜像。
- 增加 HTTPS 反向代理配置、GitHub Actions、依赖审计、部署验收、备份及回滚文档。

## 交付边界

- Chroma 1.5.9 仍有 4 个不同的未修复服务端安全公告（审计输出为 5 条，其中一条重复）。本系统仅使用嵌入模式，未启用公告涉及的 HTTP 服务端和服务端权限接口。例外范围已写入审计脚本和部署文档，不能据此声称依赖无漏洞。
- 尚未验证目标域名的证书签发、实际 Supabase 账号登录、付费模型端到端输出、实际并发容量或既有生产数据的备份恢复。远程持续集成结果以 GitHub Actions 运行记录为准。
- 本次不开放真实幼儿／家庭身份资料。可选隐私网关仍未通过发布门槛。

部署步骤见 [部署与运维](deployment.md)。本次测试使用独立数据库、Redis 和容器，验证后清理临时服务；未修改用户已有数据库记录。
